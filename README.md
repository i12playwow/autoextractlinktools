# autoextractlinktools

Extract video links from multi-tab video player interfaces via headless browser automation.

This checkout is mostly scaffolded right now. Core modules under `src/`, `bin/`, and `userscript/` are still empty and intended to be implemented next.

Project identity metadata lives in `.freebuff/project-id` and is intentionally left untracked in version control.

## Current components

- `chrome-extension/` — Chrome extension manifest, popup, icon, and (to be added) content script.
- `package.json` — project metadata, scripts, and runtime dependencies.
